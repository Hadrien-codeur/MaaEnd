## 5. 家里电脑首次接力

以下路径是示例，家里可替换成另一独立新版目录。目标目录需为空，不覆盖旧仓库。

```powershell
git clone --recurse-submodules --origin myfork --branch codex/fixed-zipline-delivery https://github.com/Hadrien-codeur/MaaEnd.git 'E:\MaaEnd V2'
Set-Location 'E:\MaaEnd V2'
git remote add origin https://github.com/MaaEnd/MaaEnd.git
git config remote.origin.pushurl DISABLED
git config remote.pushDefault myfork
git config push.default simple
git config pull.ff only
git status --short --branch
```

然后阅读本记录和规范，核对工具清单。GitHub 登录需要在该电脑独立完成，不复制另一台电脑的凭据。

若电脑已有 uv，可直接使用；否则在新仓库内下载本轮相同版本：

```powershell
New-Item -ItemType Directory -Force -Path '.cache/downloads','.cache/tools/uv' | Out-Null
gh release download 0.12.10 --repo astral-sh/uv --pattern uv-x86_64-pc-windows-msvc.zip --dir .cache/downloads
Expand-Archive -LiteralPath '.cache/downloads/uv-x86_64-pc-windows-msvc.zip' -DestinationPath '.cache/tools/uv'
. .\tools\fixed-delivery\Enter-Dev.ps1
uv sync --frozen
pnpm install --frozen-lockfile --store-dir .cache/pnpm-store
```

下载/解压命令仅用于首次安装；已有对应文件时先验证版本，不重复覆盖。随后按本记录实际完成状态补建环境：

```powershell
uv run --frozen setup-workspace
uv run --frozen build-and-install
uv run --frozen build-and-install --cpp-algo
```

`setup-workspace` 会下载依赖与预编译程序，可能选取 CI/Release；必须记录实际来源，不能自动认定与源码同一提交。涉及 C++ 修改后必须本地重新编译。资源目录联接只能指向当前新版仓库。

## 6. 日常接力与收尾

开工流程：先查看本地状态；有未提交改动时保留并辨明来源，再决定如何同步。下面 pull 和子模块更新只在工作区干净、子模块没有自有改动时执行：

```powershell
git status --short --branch
git fetch myfork
git log --oneline --left-right HEAD...myfork/codex/fixed-zipline-delivery
git pull --ff-only myfork codex/fixed-zipline-delivery
git submodule update --init --recursive
. .\tools\fixed-delivery\Enter-Dev.ps1
```

若分叉，先保留两侧提交并审查差异，不用强制覆盖。按变更更新依赖和重建 Agent，报告当前阶段、下一步后继续；总体方案已经确认，不反复要求重批。更新上游需要单独评估，不与日常同步混做。

收尾流程：更新本记录中的状态、验证、待办和环境，暂存本项目相关文件，以 `docs:` / `feat:` / `fix:` 等前缀提交，然后执行：

```powershell
git push myfork codex/fixed-zipline-delivery
git rev-parse HEAD
git ls-remote myfork refs/heads/codex/fixed-zipline-delivery
git status --short --branch
```

本地与远端提交号一致才报告已同步。安装包、日志和缓存不会随 Git 同步；游戏设施需要在新电脑按当前账号重新导入并验证。不要依赖旧聊天记录、临时目录或旧公司仓库才能继续。
