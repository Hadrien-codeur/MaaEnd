然后阅读本记录和规范，核对工具清单。GitHub 登录需要在该电脑独立完成，不复制另一台电脑的凭据。

若电脑已有 uv，可直接使用；否则在新仓库内下载本轮相同版本：

```powershell
New-Item -ItemType Directory -Force -Path '.cache/downloads','.cache/tools/uv' | Out-Null
gh release download 0.12.10 --repo astral-sh/uv --pattern uv-x86_64-pc-windows-msvc.zip --dir .cache/downloads
Expand-Archive -LiteralPath '.cache/downloads/uv-x86_64-pc-windows-msvc.zip' -DestinationPath '.cache/tools/uv'
. .\tools\fixed-delivery\Enter-Dev.ps1
uv sync --frozen
pnpm install --frozen-lockfile --store-dir .cache/pnpm-store
```

下载/解压命令仅用于首次安装；已有对应文件时先验证版本，不重复覆盖。随后按本记录实际完成状态补建环境：

```powershell
uv run --frozen setup-workspace --cpp-algo-run 34144719594
uv run --frozen build-and-install
uv run --frozen build-and-install --cpp-algo
```

`setup-workspace` 会下载依赖与预编译程序，可能选取 CI/Release；必须记录实际来源，不能自动认定与源码同一提交。涉及 C++ 修改后必须本地重新编译。资源目录联接只能指向当前新版仓库。

上面的 CI run 仅适用于本轮 `01ef330a` 业务源码基线；C++ 有改动后不得继续用该旧构建。CI artifact 也可能过期，需要本地编译或从已核实的同提交产物恢复。MaaFramework/MXU 下载脚本使用当时发布版本，家里安装后应与本记录对照，不能假定日期不同仍获得相同版本。
