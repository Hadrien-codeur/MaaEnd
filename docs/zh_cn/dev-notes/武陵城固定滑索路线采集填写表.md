## 2. 之前是怎样提供路线的

之前采用“地图确认架序 + Navigator 实录地面路径”的方式：苏白易逐架确认完整顺序；公共取货线确认两架后，另给传送落点到首架、下索到仓储的录制路径。

1. **设施资料只确认一次。** 当前安装目录已有 `install/debug/record/Ziplines.json`。同账号、设施未变时写“沿用当前快照”；新建、移动或拆过设施时，重新从主程序导入后告诉我。我负责读取模板、Level、世界坐标并匹配，不需要博士逐项手抄技术字段。
2. **地面段用 Navigator 录制。** 连接游戏，选择 `Wuling_Base` / 实际所在层级，点击“开始录制”，手动走一段，点击“停止录制”，再点“复制路径”，将 JSON 粘贴过来。分别标注“首架前”“段间”“下索后”。仅采地面路径时关闭“滑索规划”，保留工具导出的区域 / 层级字段。
3. **滑索架按实际行进顺序给出。** 在“地图图层”开启“滑索架”，单击紫色菱形可看世界坐标、模板和 Level。可以贴逐架坐标，也可以给有明确编号的地图截图或地图选点预览 JSON，我再对照当前快照核验。包括首架、所有中间架和末架；同图近邻架无法分清时再补局部详情。
4. **注明连滑和段间动作。** 哪几架之间能连续按 E、哪里要停在架上重新瞄准、哪里必须下索走到另一架，分别写清。手动跑通结果或分叉处录像可作依据。普通定位录制得到的飞行轨迹不能单独证明逐架顺序。
5. **终点记站位与朝向。** P 是人物站位，T 是面向的 NPC / 回收站 / 实测参照点，两者用同一坐标系。能直接交互可写“无需额外转向”；不清楚时写“待确认”，不手算角度。当前无订单看不到交付按钮，就写“待有单确认”，先提交到达位置。

公共段完全一致时直接写“复用苏白易首架前地面段”或“复用苏白易 #0～#N”，不要重新抄坐标；如果起步通道不同，则单独录制。苏白易编号以 [已确认架序表](./苏白易架序确认记录.md) 为准。新路线只从分叉处补新增架子，并说明共用段与新段如何连接。

世界坐标写 `x,y,z`（y 为高度）；Navigator 地面坐标一般是二维 `x,y`。不要混用旧 MapTracker 坐标。由我计算跳数和 E 预算：一个连续段有 N 架，首跳左键后需 N−2 次 E，不要求博士手填预算。
